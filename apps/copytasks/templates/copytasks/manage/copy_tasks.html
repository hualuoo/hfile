{% translate "Copy tasks" %}

{% blocktranslate %}Copies what is in a folder of one storage source, files and folders, into a folder of another one (or into another folder of the same one). The server does it, reading from the source and writing into the target at the same time: the files don't go through your computer, nor onto the server's disk. A task goes on in the background when this page is closed. Stopping one keeps what it copied; a task that failed or was stopped can be resumed, and then skips the files that are in the target with the same name and size. Users' permissions, filter rules and folder passwords don't apply to copy tasks.{% endblocktranslate %}
