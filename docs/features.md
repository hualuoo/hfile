# 功能说明

[HFile](../README.md) › [文档](README.md)

## 文件

- 文件浏览（首页 `/` 和 `/<存储源别名>/<路径>`）：
  - 首页列出自己能用的存储源（显示设置里关掉「根目录显示所有存储源」时直接打开第一个），点进去就是文件夹。地址就是文件夹的位置，可以收藏、发给别人，浏览器的后退、前进照常。上方是路径（根路径名称、存储源、每一层文件夹，放不下时中间收进「···」），右上角是切换存储源、新建和上传、个人设置（手机上收进 ⋮ 菜单）。
  - 管理员可以把存储源放进左边的导航栏（存储源的「显示在左侧栏」，默认不放）：放在首页、我的分享这几项下面，用存储源的名称和图标，点一下就打开；正在看的那个存储源是选中的一项。每个人只看到自己能用的。手机上底部导航栏放不下，存储源照旧在顶栏的「切换存储源」菜单里。存储源的图标由管理员从 33 个里选（默认是存储的图标），导航栏、「切换存储源」菜单和首页的存储源列表里都用它。
  - 列表模式（文件名、修改时间、大小，点表头排序）和图标模式，还有画廊模式：只显示这个文件夹里的图片，按原图懒加载（没有缩略图）。排序在服务器上做：不分大小写，名字里的数字按大小比（file2 在 file10 前面），文件夹总在文件前面。一个文件夹先显示「默认最大显示文件数」个，下面有「加载更多」。
  - 单击还是双击打开按「文件操作习惯」（手机上按「移动端文件操作习惯」）。勾选框、Ctrl/⌘ 加选、Shift 连选；右键菜单、每一行的 ⋮ 按钮和选中以后顶上的操作栏里是同样的操作，空白处右键是新建文件夹、上传和刷新。键盘：方向键移动，空格勾选，Enter 打开，Esc 取消选择，Ctrl/⌘+A 全选，Delete 删除，Backspace 回到上一级；iPhone、iPad 上长按打开菜单。
  - 打开文件：这一类文件有预览、又有「预览」权限时打开预览，其余的下载（显示设置里「下载前先确认」开着时先问一句）。「复制下载链接」复制的是文件现在的下载地址（完整网址），不是直链或短链。
  - 文件操作：新建文件夹（一次一层）、重命名、移动和复制（在弹出的文件夹里选目标，可以在那里新建文件夹）、删除（文件夹连同里面的东西）。目标已经有同名的文件或文件夹时一律拒绝：「目标已存在」，不覆盖、不合并。一次操作好几项时每一项各有结果，有失败的可以看详情。
  - 要密码的文件夹：打开时弹出「此文件夹已加密，请输入密码：」，「记住密码」默认勾不勾由显示设置决定；移动、删除这类操作涉及要密码的文件夹时也先问密码。「个人设置」里的「清理密码文件夹缓存」忘掉这个浏览器输过的密码。
  - 目录文档显示在列表上方、下方或弹窗里（弹窗关掉时可以选「在内容变更前不再显示」）。
  - 个人设置：列表还是图标、大小、画廊的列数和间距、图片的圆角和名字、看图时显示全部还是单张、点击放大、回到顶部按钮。记在这个浏览器里，没改过的项跟着网站的默认值。
  - 页面布局（全屏、居中、卡片）按显示设置，手机上按移动端的那一项。
- 下载：每个文件的下载地址按存储源的设置：设了下载域名的（本地、FTP、SFTP、WebDAV）是「域名 + 路径」；对象存储、OneDrive、115 这些能自己提供下载的直接从它们那里下（开了「代理下载」就经过本站）；网站是 https、存储源给的下载地址却是 http:// 的时候（局域网里的服务器、http 的镜像站、123云盘直链），换成本站的链接，经过本站下载，因为 https 的页面里用不了 http 的地址（图片和视频显示不出来，浏览器还会拦下载），不想经过本站就给存储源换上 https 的地址；其余的经过本站的签名链接 `/pd/…`，按存储源的有效期过期，或者是永久链接。经过本站的下载支持断点续传、视频拖动进度和多线程下载工具；它们用自己的线程，不占 `[server] threads`，再多也不会让页面打不开。每个存储源同时发送几个、单个 IP 同时几个和总速度可以限制（见下面的「下载和上传」和「代理下载」）。
- 上传：文件浏览里的「上传文件」「上传文件夹」，以及把文件或文件夹拖进页面（空文件夹也会建好），都交给右下角的上传面板（手机上在底部）。每个文件一行：大小、速度、已经传了多少和进度条；上传中的可以取消（先问一句），失败的可以重试，完成和排队的可以移除，关上面板时完成的就不再显示。同时最多传「站点设置」里的「最大同时上传文件数」个，其余排队；一次超过 100 个文件先确认。要「上传」权限，上传时要新建文件夹的还要「新建文件夹」（没有时跳过文件夹里的文件，并说明跳过了几个）；要密码的文件夹在面板里输入密码后接着传。
  - 同名的文件不会被悄悄换掉：面板问「覆盖」还是「跳过」（还有「全部覆盖」「全部跳过」）。覆盖会毁掉原来的文件，所以还要「删除」权限；只有「上传」时不能覆盖，面板提示「换个名字」（预先填好「名字 (1).扩展名」，新名字也被占了就再问），也可以跳过。在线编辑的保存也一样要「上传」和「删除」，只有「上传」的人看不到「编辑」。
  - 经过本站的存储（本地、FTP、SFTP、WebDAV、SMB、Google Drive、115、阿里云盘、百度网盘、123云盘这些，和打开了「代理上传」的）按 16 MB 一块上传，多大的文件都碰不到请求的大小上限，网络断了从断的那一块接着传；块都到了以后网站把文件写进存储（写进远程存储的大文件要等一会儿，面板上是「上传完成, 服务器中转中...」）。S3 类对象存储、OneDrive 和 SharePoint、又拍云、Dropbox（150 MB 以内）没有打开「代理上传」时，由浏览器直接传给存储，不经过本站；S3 类对象存储（多吉云除外，它不用设）要先在存储源的设置里点「允许本站直传（设置跨域）」；MinIO 没有按存储桶的跨域设置，默认接受所有来源，设了 `MINIO_API_CORS_ALLOW_ORIGIN` 时要把本站的地址加进去。
  - 没传完的上传在服务器上保留 24 小时，过期的由网站自动清掉（见[「运行」](deploy.md)）。
- 预览（文件浏览里打开文件时；分享页里也一样，只是不能编辑）：
  - 图片：全屏查看，放大缩小、旋转、还原、拖动，手机上双指缩放、左右滑动换一张；文件夹里的图片可以前后切换（个人设置的「双击预览模式」可以只看点的那张）。键盘：W/↑ 放大、S/↓ 缩小、A/← 上一张、D/→ 下一张、Q/E 旋转、空格还原、Esc 关闭。
  - 视频：浏览器自己的播放器，m3u8 用 hls.js 播放（分片放在 m3u8 旁边，各自用自己的签名地址）。文件夹里的视频组成播放列表，有上一个、下一个、「自动播放」和「自动播放下一个」。同名的 .vtt 和 .srt 字幕（`电影.srt`、`电影.mp4.vtt`、`电影.zh.srt`）自动加上，可以换或者关掉。外部播放器一栏：下载、迅雷、Motrix（要下载权限），PotPlayer、IINA、VLC、nPlayer、MX Player，不用时可以收起。
  - 音频：页面底部的播放条，继续浏览时接着放；文件夹里的音频组成播放列表，从点的那首开始；顺序或随机播放，列表循环、单曲循环或不循环；手机锁屏界面和耳机的按键也能控制。
  - 文本和代码：按后缀着色（highlight.js，四十来种常见语言），可以换语言、换编码（自动认出 UTF-8 和 GBK/GB18030，还有 Big5、Shift_JIS、EUC-KR、UTF-16、Windows-125x）、自动换行，底下显示行数、长度和光标位置。有「上传」和「删除」权限时（分享里没有）可以关掉「只读」直接改，Ctrl/⌘+S 或「保存」按原来的编码存回去；文件在你打开以后被别人改过时，先问要不要覆盖。
  - Markdown（.md、.markdown）：在服务器上渲染，去掉不安全的内容；同一个文件夹里的图片照常显示，链到另一个 Markdown 文件就在这里打开，代码块着色、可以一键复制；「查看源文件」转到文本查看和编辑。
  - PDF（pdf.js）：一页一页看或者连着看全部，翻页、跳到第几页、缩放、适合宽度，可以选中复制文字，中文 PDF 也能正确显示；有密码的 PDF 会先问密码。
  - kkFileView：「显示设置」里填了 kkFileView 的服务地址以后，CAD、各种 Office 格式、psd、ofd 这类文件（「kkFileView 文件后缀」）用它预览，内嵌在对话框里或者在新标签页打开；任何文件的菜单里也有「kkFileView 预览」。没填时点这些文件就是下载。
  - 太大的文件不在网页上打开，给下载：文本最多「文本预览的最大文件」（默认 512 KB，最多 10 MB），编辑最多 2 MB，Markdown 最多「文本预览的最大文件」和 2 MB 中小的那个。
- OnlyOffice（显示设置里填了「OnlyOffice 服务地址」时）：Office 文件（显示设置里的 Office 后缀，默认 doc、docx、csv、xls、xlsx、ppt、pptx、xlsm）打开时在新标签页里用 OnlyOffice 显示；有「上传」和「删除」权限、又填了 OnlyOffice Secret 时可以直接编辑：编辑器里的「保存」（Ctrl+S）马上存回存储，所有人都关掉文档以后 OnlyOffice 再存一次最终的版本。右键菜单里有「用 OnlyOffice 打开」。
  - 能编辑的人同时打开同一个文件时是同一个编辑会话（协同编辑），保存时用最后一个打开它、有编辑权限的人的身份写回；只能看的人（没有「上传」和「删除」权限的人，和分享的访客）用另一个会话，看到的是最后保存的版本，看不到正在编辑的人和他们还没保存的改动。
  - 旧的二进制格式（.doc、.xls、.ppt）只能看不能改：OnlyOffice 存回来会是 .docx 这类新格式。
  - 分享里打开 Office 文件只能看，不能改。
  - 手机上用 OnlyOffice 的手机版界面；网站是深色主题时，编辑器也用深色。
  - 没填 OnlyOffice 地址时，Office 文件用 kkFileView 打开（填了 kkFileView 地址的话），否则直接下载。
  - 文件被改名、移动、删除，或者被上传、在线编辑覆盖以后，原来的编辑会话就作废了，下次打开是新的；正在编辑的人那时还没存回来的改动不会再写进去（OnlyOffice 把它留在自己的服务器上）。
- 直链和短链：文件浏览里选中文件（一个或几个，不能是文件夹）后，右键菜单、每行的 ⋮ 和顶上的操作栏里有「获取直链」「生成短链」「同时获取」。要「直链和短链」设置里打开了对应的开关，自己有「获取直链」或「生成短链」的权限，还要有「下载」的权限（链接就是把文件交出去）。
  - 直链是 `https://网站/前缀/存储源别名/文件在存储源里的完整路径`（前缀默认 `directlink`，在设置里改）。打开它的人要能自己下载这个文件：有「下载」权限，文件在他自己的根目录里，过滤规则不挡，所在文件夹有密码的话他在这个浏览器里输入过（打开时提示「打开文件夹输入密码」）；没登录的人按匿名用户算。设置里打开「没登录的人也能用直链下载」（默认关）以后，知道地址的人都能下载，只有过滤规则还管用。
  - 短链是 `https://网站/s/8位字母数字`，生成时选一个有效期（设置里的选项，可以有「永久」）。打开短链的人什么都不用有，但每次打开都按生成它的人重新检查：他的账号还启用着、还有「生成短链」和「下载」权限、文件还在他现在的根目录里、过滤规则不挡、文件夹的密码没有改过（生成时他输入过的密码）。有一条不满足，短链就打不开了。同一个人给同一个文件再要「永久」的短链，拿到的还是原来那个。
  - 结果对话框「直链」：一个文件时显示文件名、大小、链接（点一下就复制）和二维码（可以下载 SVG 或 PNG）；几个文件时是一张表，每一列可以一次复制，「导出」保存成 CSV（Excel 直接能打开）。
  - 打开链接时先按「下载频率限制」数次数（每个 IP，直链和短链一起算，超出回答 429），再检查 Referer 防盗链（白名单或黑名单），通过以后跳转到文件真正的下载地址（和文件列表里的下载一样，见上面的「下载」，只是最多十几分钟有效）。`.m3u8` 播放列表由网站读出来直接回答。短链的 Key 猜错太多次（每个 IP 每小时 30 次）以后，这个 IP 一小时内打不开任何短链。
- 分享（`/share/<Key>`）：在文件列表里选中文件或文件夹，右键（或选中以后顶上的操作栏）「创建分享」。要登录，还要这个存储源的「创建分享链接」权限；没登录的匿名用户不能分享。
  - 「创建分享链接」对话框：分享哪些、「分享 Key」（有「自定义分享链接 key」权限才有：3 到 8 位字母、数字、`_`、`-`，留空自动生成 8 位）、「访问密码」（4 到 20 个字符，可以随机生成一个，留空就不要密码）、「有效期」（永久有效、7 天、30 天、自定义，不能选过去的时间）。建好以后显示分享链接（复制、打开链接），密码单独显示（复制），「复制带密码链接」另外有一个按钮。
  - 打开分享的人：先输入访问密码（链接里带的 `?pwd=` 只是替他填进输入框，地址栏里马上去掉）；这个浏览器 2 小时不用就要重新输入，最多 7 天。然后是和文件列表一样的界面（列表、图标、画廊），只能看分享的那几项和分享的文件夹里面的东西；能预览、下载什么，跟着分享者现在的「预览」「下载」权限，过滤规则和目录密码对他一律有效（分享者自己有「忽略隐藏」「忽略密码」也一样），文件夹里的密码在分享里输一次，只对这个分享有效。不能下载文件夹，一次下载一个文件。
  - 分享者的权限一变，分享马上跟着变：账号停用、存储源权限关掉、去掉「创建分享链接」权限、根目录改得不再包含分享的文件夹，分享就打不开；恢复以后又能打开。删掉用户或存储源，他们的分享一起删掉。
  - 「我的分享」（左边导航栏，登录以后有）：自己建的分享，可以按 Key 或名称、存储源、有效还是过期、创建时间筛选；每一条可以复制 Share Key、分享链接、访问密码、带密码的链接，打开分享，删除；「清理所有已过期分享」。「统计」是打开分享（看分享的第一层）和下载、预览文件的次数。
  - 管理页「链接」下的「分享列表」：所有人的分享，多一列「所属用户」，同样的筛选；删除别人的分享要超级管理员；「清理所有已过期分享」删掉所有人过期的分享。过期的分享不会自动删除：它一直留在这两个列表里，显示为已过期，打开时提示「分享链接已过期。」，直到分享者或管理员删除它。

## 存储源

- 存储源（管理页「存储源」）：把一个地方挂到网站上，48 种，新建时的下拉框按五类分组：
  - 本地和服务器：本地文件夹、FTP、SFTP、WebDAV、SMB（Windows 共享、NAS）；
  - 对象存储：S3 兼容存储、MinIO、阿里云 OSS、腾讯云 COS、华为云 OBS、七牛云、多吉云、又拍云、Azure Blob 存储、Bunny Storage；
  - 网盘：OneDrive 和 SharePoint（都有世纪互联版）、用应用身份访问的 OneDrive（也有世纪互联版）、Google Drive、115 网盘、阿里云盘、百度网盘、123云盘（这三个都通过开放平台）、Yandex Disk、Dropbox、GitHub 仓库、FebBox（不能上传）；
  - 自建服务：OpenList / AList、Seafile、可道云（KodBox）、Cloudreve（v3、v4）、Teldrive、Misskey、CloudFlare ImgBed、IPFS（MFS）、Emby / Jellyfin（只读）；
  - 分享链接和发布页（都是只读的）：GitHub Releases、CNB Releases、网页服务器的目录列表、URL 树、123云盘直链、OpenList 分享、联想 NAS 分享、OneDrive 分享链接（工作或学校版和 SharePoint）。

  每个存储源有名称和「别名」（网址里的名字：`/别名/文件夹/文件`）。
  - 只读的存储源：谁都没有新建文件夹、上传、重命名、移动、复制和删除的权限，权限里勾了也不算。页面上没有这些按钮，直接调接口回答「这个存储源是只读的。」
  - 不能上传的存储源（FebBox）：谁都没有上传的权限，权限里勾了也不算；页面上没有上传按钮，在线编辑只能看，直接调接口回答「这个存储源不能上传文件。」新建文件夹、重命名、移动、复制、删除照常。
  - 新建（「新建存储源」）像安装向导一样一步一步来，上面是四个步骤，做完的可以点回去改：
    1. 基本信息：名称、别名、存储类型、备注。
    2. 密钥：这种存储连接要用的几项（OneDrive、SharePoint 是应用 ID、客户端密码和租户，对象存储是 Endpoint、AccessKey、SecretKey 和存储桶，FTP、SFTP、WebDAV 是地址、用户名和密码，本地存储是文件夹，115 是应用 ID，阿里云盘是 App ID、App secret 和显示哪个盘，百度网盘是 AppKey、SecretKey 和基路径，123云盘和 FebBox 是客户端 ID 和客户端密钥），点「保存」就建好了。这时它是停用的，也不测试连接：还没授权，测了也连不上。
    3. 授权：OneDrive、SharePoint、Google Drive、阿里云盘、百度网盘、Yandex Disk、Dropbox 点「授权」，在弹出的窗口里登录并同意，回来以后令牌自动保存；115 点「扫码登录」。别的类型这一步是「测试连接」，进来就自动试一次。
    4. 其他设置：剩下的参数（基路径、SharePoint 的网站和文档库、下载加速域名……，辅助按钮也在这里）、「下载和上传」、画廊模式、图标和「显示在左侧栏」，都有默认值。点「完成」保存，再检查连接、启用；连不上就说明原因，可以改了再点，也可以「先不启用，完成」。
    第 2 步以后离开页面，存储源已经保存了（停用的）：列表里它的 ⋮ 菜单有「继续设置」，从授权接着做；也可以直接在编辑页里改。
  - 列表：拖动左边的把手排序（键盘：把手上按 Alt + ↑/↓；菜单里也有上移、下移），⋮ 菜单里编辑、过滤规则、目录密码、目录文档、检查连接、复制（连同参数、规则和所有用户的权限；115 网盘的令牌不能两个存储源共用，复制出来的先停用，重新扫码登录后再启用）、启用和停用、删除（先问一句）。连接出过错的存储源标着「出错」和原因。每一行前面是它的图标，没选过图标的是存储类型的图标。
  - 编辑页的「基本信息」里除了名称、别名、类型、备注，还有启用、画廊模式、图标（一排图标里点一个，选中的是实心的）和「显示在左侧栏」。
  - 编辑页（新建的向导里各步的字段也一样）按存储类型的参数生成：必填的标 *，每一项下面有说明（里面的网址可以点）；不常用的收在「更多设置」里。密钥一类的参数保存后不再显示，只显示「已设置」，留空就是不改，选填的可以「清除」。「测试连接」用表单里现在的值试一次，不保存；保存时先测试，连不上就不保存（停用的存储源不测试，启用时再测）。存储类型创建以后不能改。
  - 有的类型有辅助按钮：列出存储桶、查看和设置跨域、列出 SharePoint 网站和文档库、列出共享云端硬盘、115 扫码登录（弹出二维码，扫完自动填好）。编辑页上 OneDrive、SharePoint、Google Drive、阿里云盘、百度网盘、Yandex Disk、Dropbox 点「授权」：在弹出的窗口里登录并同意，回到本站的 `/storages/oauth/callback/`，令牌就填进了表单，再点「保存」（新建的向导里授权完自动保存）。这些按钮在服务器上运行，令牌、密钥这类东西一直留在服务器上，不经过浏览器。
  - 下面这些类型各要填什么、有什么限制：
    - FTP：
      - 主动模式只接受 FTP 服务器那个地址连过来的数据连接。
    - WebDAV：
      - 服务器跳转到别的协议、主机或端口（比如 http:// 跳到 https://）时不跟过去，报错并给出跳转的目标地址：把存储源的地址改成那个就行。
    - SMB：
      - 要填：服务器、共享文件夹、用户名和密码。服务器可以填名称或 IP 地址，IPv6 地址带不带方括号都行。用户名留空时用服务器的来宾账号；Windows 10 以后默认不让来宾访问。
      - 加密：可以要求用 SMB 3 加密传输；要填用户名，来宾账号不能加密。连接断开后重新连上时照样加密。
      - 服务器连不上时，一个请求最多等 10 秒，之后 10 秒内的请求直接报错；服务器重启以后，按原来的设置（来宾账号、加密）自动重新连上。
      - 上传：先写进同一个文件夹里的隐藏临时文件，再换成正式的名字，传到一半失败不会留下半个文件。要替换的文件正被别的程序打开着，或者这个账号不能修改它时，会提示出来。
      - 下载时不锁住文件：文件在 Word 这样的程序里打开着也能下载，下载的同时别人也能修改、改名或删除它。
      - 复制：文件由服务器自己复制（服务器不支持时经过本站读写）；文件夹由本站一层层建出来，里面的文件照样复制，修改时间不保留，指向文件夹的链接不复制。
      - 本站跟不过去的链接（指向服务器本地路径或者别的共享文件夹的）不显示在列表里。
      - 没有直链。
      - 这个类型用 smbprotocol 库连接，测试里用的是模拟的 SMB 接口，另有一部分测试在 smbclient 自己的代码下面模拟网络，还没有连真实的 SMB 服务器（Windows、Samba、NAS）试过。
    - Google Drive：
      - Google 文档、表格、幻灯片、绘图和 Apps Script 项目没有文件本身，下载时导出成 docx、xlsx、pptx、pdf 和 json（Google 最多导出 10 MB）。列表里显示 Drive 里的名字加上这个扩展名（「计划」显示为「计划.docx」），不显示大小，路径里也是这个名字。
    - Yandex Disk：
      - 先在 Yandex OAuth（https://oauth.yandex.com/client/new）建一个应用：权限选 Yandex Disk REST API 的读写整个网盘，Redirect URI 填本站的授权回调地址。
      - 填它的客户端 ID 和密钥，点「授权」。
      - 下载直接走 Yandex 的链接。大文件夹的移动、复制、删除在 Yandex 那边后台进行，本站最多等一分钟。名字最长 255 个字符（不是字节）。
      - 这个类型是照 Yandex Disk 的官方 REST API 文档写的，还没有用真实账号试过。
    - Azure Blob 存储：
      - 要填：存储帐户的 Blob 服务终结点（Azure 门户里存储帐户页面的「终结点」，形如 https://帐户名.blob.core.windows.net；世纪互联运营的 Azure 中国是 https://帐户名.blob.core.chinacloudapi.cn）、存储帐户名、帐户密钥（「安全性 + 网络 → 访问密钥」里的 key1 或 key2）和容器。本站用帐户密钥访问，帐户「配置」里的「允许存储帐户密钥访问」要开着。
      - 下载：私有容器的下载链接是用帐户密钥签名的 SAS，按「下载链接有效期（秒）」过期，浏览器下载时用文件原来的名字；容器能匿名读取（帐户的「允许 Blob 匿名访问」开着、容器访问级别是「Blob」或「容器」）时关掉「私有容器」，链接是不过期的普通地址。填了下载域名（自定义域名，或以 Blob 终结点为源站的 CDN，比如 Azure Front Door）时链接改用它，形如 https://域名/容器/路径，CDN 要把查询参数转发回源。
      - 上传：都经过本站，不由浏览器直传。64 MiB 以内一次传完；更大的按块上传（每块至少 8 MiB，最多 5 万块），全部传完才替换原来的文件，中途失败时原来的文件不变，传上去的块 Azure 一周后自动清掉。同名文件直接覆盖。
      - 重命名、移动、复制：在 Azure 里复制，移动再删掉原来的；文件夹要一个个文件来，不是一步完成的。Azure 有时在后台慢慢复制，本站每个文件最多等 10 分钟，超时就取消这次复制，原来的文件不动。删除文件夹也是逐个删除；帐户开了软删除时，删掉的文件在保留期内可以在门户里恢复。文件夹里有别的程序建的、名字里带 `.` 或 `..` 这一段的 Blob 时（请求的地址里写不出这种名字），本站不删除这个文件夹，提示先在 Azure 门户里删掉那个 Blob；移动、复制文件夹时这种 Blob 留在原处。
      - 文件夹：空文件夹存成一个带 hdi_isfolder 元数据的「文件夹名/」标记，AzCopy、Hadoop 这些工具留下的文件夹标记也认。开了分层命名空间（Data Lake Storage Gen2）的帐户照样能用，文件夹是真的，删空了还在；用 Data Lake 接口建的大文件不能分块替换，要先删掉再上传。
      - 限制：名字以点结尾的文件和文件夹不能新建（Azure 会去掉结尾的点，变成另一个名字），已有的也不显示；完整路径最多 1024 个字符；单个文件最大约 190.7 TiB；路径编码后超过 2 KiB 的文件不能重命名、移动、复制。不支持搜索。
      - 这个类型是照 Azure 的官方文档写的，还没有用真实账号试过。
    - Bunny Storage：
      - 要填：存储区（Storage Zone）名称、它的密码和主区域，都在 bunny.net 控制台里这个存储区的「Access」页（API / HTTP）上；密码不是只读密码，也不是账号的 API 密钥。区域选项括号里是它的 Endpoint，和那一页上写的一致。
      - 下载：默认经过本站。填了「Pull Zone 地址」（以这个存储区为源站的 Pull Zone，写成 https://它的 b-cdn.net 主机名或自定义主机名）后，下载直接走 Pull Zone，链接由本站算出，不用问 Bunny。Pull Zone 在「Security」里开了 Token Authentication 时，把「URL Token Authentication Key」填进「Token 认证密钥」，链接会带上按「下载链接有效期（秒）」过期的令牌。Pull Zone 没开 Token Authentication 时，任何人知道地址都能下载这个存储区里的任何文件，包括不在基路径下的、本站隐藏的和设了目录密码的文件。名字里有空格、中文这类要编码的字符时，带令牌的链接能不能通过还没验证过，不行就打开「代理下载」。Pull Zone 不发 Content-Disposition，浏览器按链接最后一段（文件名）保存；文件替换或删除以后，Pull Zone 的缓存过期或被清除之前可能还给旧的内容。
      - 上传：都经过本站，不由浏览器直传，一次 PUT 传完。能回读的数据先算 SHA-256 一起发过去，Bunny 收到的对不上就拒收。同名文件直接覆盖。
      - 文件夹是真的，可以建空文件夹；删除文件夹由 Bunny 一次连里面的东西一起删掉。
      - 重命名、移动、复制：Bunny 都没有。重命名文件是先下载、再用新名字上传、最后删掉旧的，不是一步完成的；文件夹不能重命名。不能移动；复制由本站一个个文件下载再上传，不能复制文件夹。
      - 限制：名字开头和结尾不能是空格，完整路径最多 6000 个字符。不支持搜索。
      - 这个类型是照 Bunny 的官方文档和官方 SDK 的源代码写的，还没有用真实账号试过。

      - 上传：150 MB 以内的文件由浏览器直接传给 Dropbox（一次性的上传链接，不用设置跨域），更大的经过本站分块上传。单个文件最大 350 GB。

    - 阿里云盘（开放平台）：
      - 先在阿里云盘开放平台（www.alipan.com/developer）建应用：回调地址填本站的授权回调地址（域名要和本站的一样），权限选 user:base、file:all:read、file:all:write。
      - 填 App ID 和 App secret，选显示「资源库」还是「备份盘」，点「授权」，登录阿里云盘并允许。授权时阿里云盘会要求同时允许资源库和备份盘：它对一个应用只记最后一次授权时选的盘，这样同一个应用给两个盘各建一个存储源也都能用。刷新令牌 90 天有效，每次刷新都换一个新的，HFile 自动保存；在阿里云盘 App 里取消了授权要重新授权。
      - 下载：都经过本站。阿里云盘规定不能把下载地址给别人用，下载地址被几个 IP 用过的账号会被封，基本解不了封，所以本站不把它的下载地址交给浏览器。普通应用同时只能下几个（每秒 3 个），满了等几秒再试。被冻结的文件不能下载；资源库里被限制下载的文件（阿里云盘允许从备份盘下载）在资源库的存储源里不能下载；iPhone 的实况照片（.livp）阿里云盘只给分开的图片和视频，也不能下载。
      - 上传：经过本站，按 20 MB 分片传；阿里云盘已经有的文件秒传，不用真传。阿里云盘不能覆盖文件：替换时先传新的，再把旧的放进回收站。

      - 限制：阿里云盘按账号限制请求次数（文件列表每 10 秒 40 次，其余每秒 15 次），超了要等，很大的文件夹第一次打开比较慢；名字最长 1024 字节。阿里云盘不许把开放接口用来做图床、下载站、视频站这类公开分发，拿来大量公开分享可能让应用被降级或封禁。
      - 这个类型是照阿里云盘的官方文档写的，还没有用真实账号试过。
    - 百度网盘（开放平台）：
      - 先在百度网盘开放平台（pan.baidu.com/union）完成实名认证，再在控制台建一个应用：类型选「软件」，用途选「个人使用」（不用审核，建好就能用，最多 10 个用户；选「公开发布」的应用在通过上线审核以前，百度只给很少的测试调用次数）。在应用详情的「安全设置」里把本站的授权回调地址加进「授权回调页」：百度只收公网地址，改了以后最多一小时才生效。

      - 限制：能传多大、什么类型、网盘多大由账号的角色决定：「可上传的最大文件大小」默认 30 MB；「可上传的文件类型」默认只有文本、JSON、图片、音频和视频，压缩包、PDF、空文件这些默认都传不了；「网盘容量」默认 100 MB。管理员和监察员不受这三项限制。整个服务器还有配置文件里的 maxFileSize（默认 250 MiB），Misskey 前面的反向代理也要放得下这么大的请求。每个账号每小时最多新建 10 个文件夹、上传 120 个文件（角色的「速率限制」可以放宽），超了要等。
      - 删除的东西直接删掉：Misskey 没有回收站，帖子里附带的这个文件也会一起消失。删除文件夹时要一个一个删掉里面的东西，东西多的要等一会儿。复制文件由本站下载再上传（Misskey 没有复制的接口），不能复制文件夹。
      - 名字区分大小写；文件名最长 200 字节，不能有「..」；文件夹名最多 128 个字符。
      - 这个类型是照 Misskey 的文档、API 定义和源代码写的，还没有用真实的 Misskey 服务器试过。
    - CloudFlare ImgBed：
      - 要填：ImgBed 站点的地址（就是浏览器里打开它的那个地址）、API Token 和上传渠道。API Token 在 ImgBed 的管理界面「系统设置 → 安全设置 → API Token 管理」里创建（只显示一次），要给 list、upload、delete 权限；要重命名、移动和替换同名文件，还要给 manage 权限（有了它，这个 Token 也能管理 ImgBed 的 Token 和设置）。上传渠道选 ImgBed 里已经配好的一种（Telegram、Cloudflare R2、S3、Discord、Hugging Face、WebDAV），同一种有好几个时可以在「渠道名称」里指定。基路径可以是 ImgBed 里的一个文件夹。
      - Token 只放在请求头里，不放进网址，也不会发给 Hugging Face。
      - 下载：浏览器直接用 ImgBed 的文件链接（/file/...）下载。这些链接公开、永久有效，知道链接的人都能打开；不想交出链接就打开「代理下载」。浏览器拿到的文件名是上传时的名字（改名后也不变），图片这类文件会直接在浏览器里打开。被 ImgBed 拉黑、标成成人内容，或者 ImgBed 开了白名单模式而不在白名单里的文件，本站也读不了。
      - 外链渠道（External）的文件 ImgBed 只存了一个链接，列表里不显示大小，本站读的时候跟着 ImgBed 的跳转去那个链接取。浏览器打开和预览时也跟着跳转过去，所以 ImgBed 存储源的文件夹页面允许任何 http 和 https 网站的图片和视频（CSP）；本站是 https 而链接是 http:// 的，浏览器会改用 https 去取或者直接拦下。ImgBed 没设用户认证码时谁都能传这种文件，所以和 URL 树一样，ImgBed 的地址在互联网上时，跳转到本站所在网络里的地址（127.0.0.1、192.168.x.x，云服务器的元数据地址 169.254.169.254、100.100.100.200 这类）不跟过去，名字解析到那里的也一样，都报错；ImgBed 本身在局域网里的不限制。
      - 上传经过本站，文件名原样保留，Telegram 渠道的图片也不会被压缩。Telegram、R2、S3 渠道大于 20 MiB 的文件按 16 MiB 分块上传，Discord 大于 9 MiB 的按 9 MiB 分块；Hugging Face 渠道 20 MiB 及以上的文件由本站直接传到 Hugging Face（先算一遍 SHA-256，Hugging Face 已经有的内容不再重传）；WebDAV 渠道不能分块，一个文件一个请求，ImgBed 部署在 Cloudflare 上时最大 100 MB。ImgBed 开了文件有效期时，传上去的文件按它的默认有效期到期。
      - ImgBed 从不覆盖同名文件，所以替换同名文件时先上传（ImgBed 会把它存成「名字(1).扩展名」；直接传到 Hugging Face 的文件先用一个临时的名字「hfile-…」），再删掉旧文件、把新文件改回原名；Token 没有 manage 权限，或者 ImgBed 删不掉旧文件时，替换会失败，新传的文件删掉，旧文件保持原样。
      - 没有空文件夹：新建文件夹其实什么也不建，往里面传了文件才会出现。文件夹改名、移动是一个一个文件改名完成的，文件多的要等一会儿；中途失败时一部分文件已经在新位置（报错里会说移了几个）。不能复制文件夹（复制文件由本站转存）。旧版 Telegram 渠道和 Telegraph 上的文件不能改名、移动。
      - 删除是直接删掉，没有回收站。文件夹或者里面的文件夹名字里有 `#`、`&`、`+`、`%` 这类字符（ImgBed 2.6 以前允许）时，本站一个一个文件删，慢一些：ImgBed 自己删这样的文件夹会列错文件夹，删掉别的文件。
      - 名字里不能有空格、`` \ : * ? " ' < > | ( ) [ ] { } # % ^ ` ~ ; @ & = + $ , `` 和 `..`，开头和结尾也不能有空白字符：ImgBed 会把它们改成「_」，文件就不在原来的位置了。名字区分大小写。ImgBed 2.6 以前建的名字里有 `..` 的文件夹，ImgBed 自己列不出来，本站打开、改名、移动、删除它和里面的文件都会报错。
      - ImgBed 回答之后才更新它的文件索引，刚改完时列表可能还没变，过一会儿刷新就好。ImgBed 让浏览器把文件缓存 30 天（每种部署都一样），所以本站给的文件链接后面带着文件的上传时间（?v=…，本站一小时内列过这个文件时才带），替换以后链接就变了，浏览器和 CDN 都会去取新的；没带的链接和以前拿到的链接可能还会打开旧文件。本站自己读文件不受影响。
      - 这个类型是照 ImgBed 的官方文档和源代码（v2.7.8）写的，还没有用真实的 ImgBed 站点试过。

  - 目录密码：按顺序第一条管到这个路径的规则决定要哪个密码。访问者输对一次，这个浏览器就记住了（勾「记住密码」记 30 天），改了规则的表达式或密码要重新输；密码输错太多次（每个 IP 每分钟 10 次）要等一会儿。有「忽略密码」权限的用户不用输（分享里除外）。
  - 目录文档：按顺序第一条匹配这个文件夹的规则，它的 Markdown 显示在列表上面、下面或弹窗里（和文件夹里的 README.md 一样按不信任的内容渲染：脚本、样式、表单会被去掉）；可以按用户自己的根目录（相对路径）或按存储源的路径（绝对路径）匹配；也可以改成读取文件夹里的 README.md。
  - 规则的写法：表达式写的是存储源里的路径，从存储源的根目录（基路径）算起，和用户自己的根目录无关（目录文档按相对路径匹配的除外）；`*` 是一段里的任意字符，`?` 是一个字符，`**` 跨任意多段；`/dir` 是文件夹本身，`/dir/*` 是直接在它里面的，`/dir/**` 是它下面的所有东西；`*.txt` 是存储源最上层的 .txt 文件，`**/*.txt` 或 `**.txt` 是任何地方的。不分大小写，名字末尾的点和空格不算，`\` 和 `/` 一样是分隔符（Windows 上的 FTP、WebDAV 服务器把 `secret\a.txt` 当成 secret 里的文件）。
- 复制任务（管理页「存储」下的「复制任务」）：把一个存储源的文件夹复制到另一个存储源的文件夹里，也可以是同一个存储源的另一个文件夹。和文件列表里的「复制」一样，源文件夹本身也复制过去：从 `/a` 复制到 `/b`，复制出来的是 `/b/a`（任务列表里显示的目标就是它），里面是 `/a` 里的文件和文件夹；源文件夹选的是根目录时，它没有名字，里面的东西直接复制到目标文件夹里。目标文件夹不存在时会新建，空的文件夹也照样建出来。复制出来的文件和文件夹的修改时间是复制的时刻，不保留原来的。
  - `/b/a` 已经有了就复制进去，里面原有的东西留着，同名的文件照下面的设置跳过或覆盖。`/b/a` 是一个文件，或者目标存储源不能用 `a` 这个名字（比如名字里有这种存储不能用的字符）时，任务建不了。
  - 同一个存储源里，源文件夹和复制出来的文件夹不能是同一个，也不能一个在另一个里面：从 `/a` 不能复制到 `/`（复制出来的就是 `/a` 自己）或者 `/a` 下面的文件夹，从 `/a/b` 复制到 `/` 可以（复制出来的是 `/b`）。
  - 新建时选从哪个存储源的哪个文件夹复制到哪个存储源的哪个文件夹（点输入框里的按钮一层层选，也可以直接填路径），再设：
    - 线程数：同时复制几个文件，1 到 16，默认 4。FTP、SFTP 复制一个文件要一直占着一个连接（同一个存储源复制到自己时占两个），所以同时复制的文件最多是这个存储源的「最大连接数」减一（自己复制到自己时再减半），留一个给列文件夹；
    - 总限速：所有线程加起来最快多少 MB/秒，0（默认）为不限速；
    - 目标里有文件名和大小都相同的文件时：跳过（默认）或覆盖；
    - 目标里有文件名相同、大小不同的文件时：覆盖（默认）或跳过；
    - 失败重试次数：0 到 10，默认 3。每次重试前等 1、2、4……秒（最多 30 秒）；源文件不见了、目标不接受这个名字（比如名字里有这种存储不能用的字符）、目标在那里有同名的文件夹这类重试也没用的错误不重试。列文件夹、在目标里建文件夹出错时也一样重试。
  - 只读的存储源和不能上传的 FebBox 只能当源，不能当目标；停用的存储源不能选。
  - 本地存储源会跟着文件夹里指向文件夹里面的链接走：一个文件夹列出来和它上面的某个文件夹完全一样时（多半是指回上层的链接），不进去，记成没复制成功，不然会一层套一层地复制下去。
  - 不落盘：服务器一边从源存储源读、一边写进目标，文件不经过浏览器，也不先存到服务器的硬盘上。百度网盘、115 网盘、123云盘和 CloudFlare ImgBed 要先算出整个文件的哈希才能上传，复制到它们时每个文件从源读两遍（流量是文件的两倍），同样不存到硬盘上。
  - 任务在服务器的后台运行，关掉页面也不影响，可以同时运行几个。列表里每个任务显示状态、从哪里到哪里、进度（大小和文件数；还在列出文件时总数会变大）、速度和大约还要多久，结束的显示用时和平均速度。点开以后看任务的设置和复制、跳过、失败了多少，正在复制的每个文件的进度、速度、第几次尝试和上一次的错误，以及没复制成功的文件和文件夹各自的原因。任务运行时页面每 1.5 秒刷新一次。
  - 详细日志（任务右边的「详细日志」按钮）：按时间先后记下每次运行做了什么，最新的在最上面，一次显示 100 条，「加载更早的」往前翻。记的有：每次运行的开始和结束（结束的状态和原因）；每个文件复制成功（大小、用时、速度，第几次尝试成功）、跳过（目标里有文件名和大小都相同的文件，或者文件名相同、大小不同而设置是跳过）、某一次尝试失败、等几秒再试（那一次的错误）、最后没复制成功（原因、试了几次）；没能复制的文件夹。最上面是正在复制的文件和它们的进度；任务运行时，开着的日志每 1.5 秒更新一次。
  - 详细日志全部留着：继续复制时不清掉，也不会自动删除。每条大约 150 字节，文件很多、或者继续了很多次的任务会让数据库变大（比如 100 万个文件约 150 MB）。以前的版本运行的任务没有日志，下一次运行起才有。
  - 停止：已经复制好的文件留在目标里，正在复制的文件中途停下（各种存储源上传到一半失败时怎样，见上面各类型的说明）。
  - 继续：失败或停止的任务可以继续复制：重新列出源文件夹，目标里文件名和大小都相同的文件跳过（不管新建时「相同文件」选的是跳过还是覆盖），其余的照任务的设置复制，上一次的失败记录清掉（详细日志留着）。
  - 存储源的账号或授权失效、存储源被删除、停用或者改了设置时，任务停下并写明原因，处理好以后可以继续复制。网站停止（包括升级后的重启）时正在运行的任务记成中断；程序被强行结束、来不及记的，1 分钟以后显示为中断。都可以继续复制。
  - 复制任务直接读写存储源，不受用户的权限、过滤规则和目录密码限制。新建、停止和继续复制任务记进操作日志，复制的每个文件不记。

## 账号

- 登录：页面右上角的「登录」打开登录框，用户名不分大小写；旁边的按钮选主题（跟随系统、浅色、深色）。也可以打开登录页 `/login/`。登录后右上角是自己的名字，点开的菜单里有「修改密码」、主题和「退出」。改密码以后，这个浏览器保持登录，别的设备上的登录失效。
  - 图片验证码：「安全设置」里开了「登录要输入图片验证码」时，每次用密码登录都要先输入图片里的 4 个字符（管理员也要），Django 后台的登录页也一样。不区分大小写，看不清就点图片换一张；每张图只能试一次，输错了、密码错了都换一张新的。
  - 两步验证（超级管理员）：右上角菜单里的「两步验证」，用手机上的验证器 App（Google 身份验证器、Microsoft Authenticator 等）扫二维码，输入 App 上的 6 位数字和登录密码就开启了。以后登录输完密码，还要输入 App 上当时的 6 位数字；每个数字只能用一次。关掉要输密码。手机丢了、登录不了时在服务器上运行 `hfile resetadmin`。
  - 登录安全入口：「安全设置」里设了「登录安全入口」（比如 `door-42`）以后，只能在 `https://网站/login/door-42/` 登录，`/login/` 和别的地址都是 404，页面上不再有登录按钮，防止登录页被扫描（入口越长越难猜，别用 admin、login 这类词）。猜错的入口和登录一起算次数：一个 IP 一分钟里猜错加上登录失败满 10 次，接下来一会儿所有 `/login/…` 都回答「太频繁了」（猜对的也一样），所以没法很快地猜出入口。访问记录里入口写成 `/login/<entry>/`。Django 后台的登录页也不让登录了：先从入口登录网站，再打开后台。忘了入口时运行 `hfile resetadmin`，它会显示登录地址。「显示登录入口」关掉时只是不显示登录按钮，登录框和登录页照样能用。
- 单点登录（SSO，管理页「用户」下的「单点登录」）：用 GitHub、Gitee、GitLab，或者 OpenID Connect 服务（Logto、Keycloak、Authentik 等）的账号登录。
  - 登录：登录框和登录页下面有每个启用的服务商的图标，点一下到服务商那里同意，回来就登录了，回到原来的页面；开着两步验证的超级管理员回来以后还要输入 6 位数字。设了登录安全入口时，图标在 `/login/<入口>/` 上，单点登录（`/sso/<简称>/login`）照样能用：入口是为了不让扫描程序找到密码登录框，单点登录猜不出账号。
  - 绑定：服务商的账号按它那边不会变的用户 ID 绑定到网站的一个用户上，每个服务商一个；从来不按用户名对应（服务商那边叫 admin 的人不会因此登录成这里的 admin）。登录以后在右上角菜单的「账号绑定」里自己绑定或者解除（绑定要输一次登录密码；没有密码的账号不能解除最后一个能用的绑定，先设密码）；管理员也可以在用户编辑框的「单点登录」页里替他绑定（填服务商那边的用户 ID）或者解除，但不能这样给自己绑定，其他管理员的绑定只有超级管理员能看和改。
  - 没绑定的人：「安全设置」里开了「允许单点登录自动注册新用户」时，第一次用单点登录就自动建一个账号：权限照「虚拟新用户」（默认权限和存储源权限），不会是管理员，用户名用服务商给的（被占用了或者不合规就用「简称_用户 ID」），昵称也用服务商给的。没开时页面告诉他先用密码登录、再绑定，或者找管理员；操作日志里记下「简称:用户 ID」，管理员照着就能替他绑定。
  - 单点登录建的账号没有密码：右上角菜单里是「设置密码」，不用填原密码，设好以后也能用用户名和密码登录。
  - 管理：新增时可以选 GitHub、Gitee、GitLab、Logto 和通用 OpenID Connect 的预设（端点、Scope、用户 ID 等字段都填好了），表单上显示要在服务商那里登记的回调地址，可以复制；OpenID Connect 服务可以「通过 .well-known 地址自动填写」三个端点。Client Secret 加密保存，保存后不再显示。可以启用、停用、调整登录页上的顺序、删除（绑定的账号一起删掉，用户还在）。这些设置只有超级管理员能改（服务商的设置决定了它的哪个账号登录成哪个用户），其他管理员只能看。
- 用户管理（管理页的「用户」）：用户列表（搜索用户名、昵称或 ID，按启用状态筛选），新建、编辑、复制、启用和停用、删除。编辑框有四页：基本信息（用户名、昵称、密码、启用）、默认权限（以后新增存储源时这个用户自动得到的权限，从 15 种里勾，比如上传、下载、获取直链，大多有说明）、存储源权限（每个存储源的根目录、开关和权限，由存储源管理提供）、单点登录（替他绑定或解除，见上面的「绑定」）。
  - 前置权限：有的权限要先勾它的前置才能勾：「预览」「复制下载链接」「获取直链」「生成短链」要先有「下载」（它们都把文件的内容交出去：预览时浏览器拿到的就是文件，能预览就能存下来），「自定义分享链接 key」要先有「创建分享链接」。前置没勾时它们是灰的，去掉前置时一起去掉勾，再勾上前置时被一起去掉的勾会还回来；默认权限和存储源权限的对话框都这样。一次设置几个存储源的权限时，手动去掉的勾从每个存储源去掉，因为前置没勾而灰着的只在还有它的前置的存储源里保留。
  - 内置的「匿名用户」是没登录的访客：它的权限就是访客能做的事，停用它，没登录就什么都看不了。「虚拟新用户」是以后单点登录新建的账号一开始的样子。这两个不能改名、没有密码、不能删除，也不能登录。
  - 复制用户：起一个新用户名（可以顺便设密码），新用户有原来那个人的默认权限、每个存储源的权限和启用状态，但不复制密码、管理员身份和两步验证；不设密码的话，新用户暂时不能用密码登录。
  - 停用一个账号，他马上被退出，以后重新启用也不会恢复那些登录；管理员给别人改了密码，那个人在所有设备上的登录也失效。
  - 不能停用、删除自己，也不能在这里改自己的密码（用右上角的「修改密码」，要输原密码）；最后一个能用的超级管理员不能停用、删除，也不能在后台去掉管理员身份；超级管理员和其他管理员的账号只有超级管理员能改、能复制。这里不能把人设成管理员：超级管理员由安装向导、`createsuperuser` 命令或后台设置。
- 登录也记在操作日志里（见「网站管理」）：网站和后台的每次登录的时间、IP、浏览器，没成功的还有原因（密码不对、没有这个用户、账号已停用、验证码不对、两步验证没通过、太频繁被拦下、单点登录的账号没绑定等）、输入的用户名和它对上的账号。不记录密码，也不记退出登录。

## 网站管理

- 管理页 `/manage/`（管理员）：左边的菜单分组列出各页。「系统」下有「版本与升级」：程序版本、数据库和程序是否一致、启动时是否自动升级、备份文件夹，以及升级记录（什么时候从哪个版本升到哪个版本、执行了哪些迁移、升级前的备份在哪），这里只能看，不能升级或恢复；还有「诊断信息」和「IP 归属地」（见下）。菜单的最后是 Django 自带的管理后台（下面叫「后台」），它的地址是随机的。
- 网站的设置（管理页「站点」下的六页）：
  - 站点设置：站点名称（浏览器标题和左上角）、网站图标、左上角的 Logo 和点它打开的地址、文件列表上方路径的第一段（默认「首页」）、备案号、同时上传几个文件。图标和 Logo 可以上传（网站图标：PNG、ICO、WebP、JPG、GIF；Logo：PNG、WebP、JPG、GIF；最大 1 MB，网站检查后重新编码成 PNG 保存），也可以填一个 http(s) 图片地址；都不填用 HFile 自己的。
  - 显示设置：页面布局、单击还是双击打开、默认排序、一次显示多少文件；各类预览（图像、视频、音频、文本、Office、kkFileView）的开关和文件后缀（空着用默认的，「恢复默认」一键填回）；OnlyOffice 和 kkFileView 的地址（OnlyOffice 的 Secret 加密保存，填了以后不再显示）；公告；自定义 CSS 和 JS。OnlyOffice 的地址和 Secret、kkFileView 的地址、公告、自定义 CSS 和 JS 只有超级管理员能改，其他管理员看到的是锁着的：OnlyOffice 的编辑器脚本从它的地址加载，以打开文件的人的身份在网站上运行，Secret 给保存文件的回调签名，kkFileView 会拿到要预览的文件，公告和自定义的代码原样用在公开页面上。
  - 直链和短链：下载日志、Referer 防盗链（白名单或黑名单）、单个 IP 的下载频率限制、直链的开关和地址前缀（不能和网站自己的地址、存储源的别名、后台地址重名）、没登录的人能不能用直链、短链的开关和可选的有效期（可以调顺序，可以有一个「永久」）。
  - 代理下载：单个 IP 同时能有几个经过本站的下载（下载工具的每个连接、画廊加载的每张图片都算一个，再多的得到 429），和它所有经过本站的下载加起来最快多少（KB/s，开再多连接也不会更快）；默认都不限。每个存储源自己的同时连接数在它的「下载和上传」里。
  - 安全设置：登录安全入口、是否显示登录按钮、没登录的人看到的首页（正常显示、跳转到登录页、自定义页面）、图片验证码、单点登录自动注册（这些登录相关的功能由账号部分实现）。其中「自定义页面」只有超级管理员能改：它原样用在公开页面上，和自定义 JS 一样。
  - 访问控制：IP 黑名单（IP 或 IP 段，支持 IPv6）和 UA 黑名单（* 通配符），名单上的访问者打开任何地址都是 403；页面上显示网站看到的你的 IP 和浏览器，可以当场测试一个 IP 或 UA 会不会被挡住，「屏蔽迅雷下载」一键加上迅雷的规则。会挡住你自己的名单保存不了。

  每一项保存时都由服务器检查，有错一次全部标在对应的项旁边；改了马上生效，不用重启。
- 外观：首页、文件页和分享页（「公开页面」）上方显示公告（Markdown，可以写 HTML；访客可以关掉，内容改了会重新显示），窗口最底下一直显示备案号和「Powered by HFile」（滚动时也不动，文件从它下面滚过；手机上在底部导航栏上面，播放音频时在播放条上面；HFile 链接到项目的 GitHub 页面），并加上管理员的自定义 CSS 和 JS。管理页、登录页和安装页上没有这些，自定义的脚本出了问题也能登录进来改掉它；放了自定义 JS 的页面上也不输密码：「登录」打开登录页 `/login/`（登录后回到原来的页面），「修改密码」「两步验证」「账号绑定」换到不带它的同一个页面。这防的是统计代码这类脚本无意中记下密码，挡不住有意读密码的脚本：只放信得过的代码。
- 没登录的人看到的首页：正常显示文件；跳转到登录页 `/login/`（登录后回到原来要打开的地址；设了登录安全入口时只显示「要登录才能使用」，不透露入口）；或者管理员写的一个页面（只写正文的话会套上网站的名称、图标和样式）。
- 短链管理和下载日志（管理页「链接」下）：
  - 短链管理：所有短链，可以按存储源、路径、Key、创建日期筛选，按创建时间、过期时间或 Key 排序；删除一个、删除选中的（它们的下载日志留着）、「删除过期短链」（连同它们的下载日志）；「导出」把筛选出的全部短链存成 CSV；「统计信息」显示下载频率限制现在记着的每个 IP 的次数和到期时间。过期的短链不会自动删除：它留在列表里，显示为已过期，打开时回答「短链已失效。」，它的下载日志也留着，直到管理员删除它。
  - 下载日志：开着「记录下载日志」时，每一次通过直链、短链的下载记一条：时间、存储源、直链还是短链（短链的 Key）、文件路径、用户（下载时登录着的账号，没登录是空的）、IP（启用了「IP 归属地」时带着它的归属地）、浏览器（User-Agent）和来源网页（Referer）。同一个 IP、同一个用户 10 分钟内打开同一个链接只记一条：下载工具分段下载、先发 HEAD 再下载、断点续传都会重新打开链接，算一次下载；被拦下的（频率、防盗链、没有权限、短链失效）不记；`wget -N`、`curl -z` 这类「有更新才下载」的请求，文件没改时链接直接回答没有改（304），也不记。在文件列表或预览里点「下载」、经过本站转发（`/pd/` 链接，包括跳转到 OneDrive、115 的）的下载也记，类型是「页面下载」：开始下载的那一次记一条，同一个 IP、同一个用户 10 分钟内下载同一个文件也只记一条（IDM 这类下载工具从浏览器接过下载时，会再从头要一次）；断点续传、下载工具分段要的后面几段和 HEAD 不记，失败的不记；预览、看图、播放视频和复制出去的下载链接不记。点「下载」直接从存储源自己的地址下载的（对象存储的直连地址、下载域名）网站看不到，不记；分享里的下载只算进分享的下载次数。可以按这些筛选，删除选中的，或者删除列表上这些条件查到的全部（列表显示以后才记下的不删）。
- 操作日志（管理页「用户」下）：每一条有时间、IP（启用了「IP 归属地」时带着它的归属地）、浏览器、谁、做了什么、对什么和详情，只能新增，不能修改或删除，也没有开关。记的有：
  - 账号：登录和没成功的登录（见「账号」）、修改或设置密码、开启和关闭两步验证、绑定和解除单点登录、单点登录自动注册。
  - 文件：新建文件夹（也包括上传文件夹时建的）、重命名、移动、复制、删除（文件夹连同里面的东西是一条）、上传（覆盖了原来的文件时写明）、在线编辑（文本编辑器和 OnlyOffice 的每次保存，OnlyOffice 的记成编辑会话的用户、没有 IP）。一次操作好几项时每一项一条，没成功的不记。没登录的访客记成「匿名用户」。浏览、预览和下载不记：下载在「下载日志」里。
  - 链接和分享：生成短链（每个文件一条，带有效期）、创建分享（分享了哪些、有没有访问密码、有效期）、删除分享、清理过期分享。获取直链不记：直链是算出来的，什么也没存。
  - 用户管理：新建、修改（改了用户名、昵称、密码、启用，加上和去掉了哪些默认权限）、复制、删除用户，修改存储源权限（哪个存储源给了、去掉了、改了根目录或权限），替用户绑定和解除单点登录。
  - 存储源管理：新建、修改（改了名称、别名，以及改了哪些选项和参数，参数只记名字不记值）、删除、启用、停用、复制、调整顺序、更换链接密钥，修改过滤规则、目录密码、目录文档（加了、改了、删了几条），新建、停止和继续复制任务（新建的记下从哪里复制到哪里和任务的设置）。
  - 网站管理：修改设置（哪一页的哪几项，不记内容，网站图标和 Logo 也算）、新增、修改、删除单点登录和调整顺序、删除短链和下载日志（删了多少条）、启用和停用 IP 归属地、下载 IP 归属地数据库（有新数据时）、补全 IP 归属地（有变化时）、安装、`hfile resetadmin`（没有 IP）。
  - 用户名、存储源名称另存了一份：账号或存储源删了，记录照样看得懂，只是没有链接了。可以按操作（一种或一组）、存储源、日期筛选，搜索用户名、昵称、存储源名称、路径、Key 或 IP 开头；点某条记录的用户或 IP 只看相关的记录，用户列表每一行的「操作日志」按钮也一样。以前的「登录日志」并进了这里：升级时它的记录搬进操作日志，「安全设置」里的「登录日志」开关去掉了。后台里的修改不记。
- 诊断信息（管理页「系统」下）：网站从这个请求看到的你的 IP、协议和地址，和设置文件里的 `[site] url`、`[server] proxies` 对照，指出反向代理哪里没配对；列出请求头：只显示浏览器常发的和代理、CDN 加的这些已知无害的请求头的值（地址里的口令也像访问记录一样打了码），别的请求头只列名字、值隐藏（CDN 回源的密钥这类自定义的请求头，从名字看不出是不是机密），Cookie 只列名字；可以复制。
- IP 归属地（管理页「系统」下）：启用后，用户列表和用户编辑框里的最近登录 IP、操作日志、下载日志和后台的用户页里，每个 IP 旁边都显示它在哪里：国家或地区，用城市数据库时很多 IP 还有省（州）和城市，比如「223.5.5.5 中国 浙江 杭州」（用国家数据库时是「223.5.5.5 中国」）「8.8.8.8 美国」「202.67.240.1 中国香港」「192.168.1.1 内网」；英文界面显示英文名，从小写到大（「Hangzhou, Zhejiang, China」）。没有运营商。
  - 数据库二选一，都是 MaxMind 的：城市数据库 GeoLite2-City（`GeoLite2-City.mmdb`，约 50 MB，有国家或地区、省和城市），或者国家数据库 GeoLite2-Country（`GeoLite2-Country.mmdb`，约 3 MB，只有国家或地区；网站把数据库整个读进内存，它占的少得多）。从 [ip.adysec.com](https://ip.adysec.com/) 下载：它（[adysec/IP_database](https://github.com/adysec/IP_database)）每天转存一次 MaxMind 的文件，不用注册 MaxMind 的账号。文件放在服务器上的 `[paths] geoip` 文件夹，查询在本机完成，IP 不会发给别人。启用后才能下载。服务器要经过代理才能上网时，启动程序前设好环境变量 `https_proxy`。
  - 显示的名字：省只显示最大的一级（英国显示「英格兰」，不显示它下面的郡）；同一个地方的两个名字只留一个，「北京市」里的「北京」显示成「中国 北京」，香港的城市「香港」不再重复；数据里没有中文名的地方显示英文名；查不到的显示「未知」。
  - 下载在后台进行，页面上显示下了多少。ip.adysec.com 不发布校验值，下完先试着打开一次，确认是选的那种数据库、支持 IPv6、查两个地址不出错，才换上。MaxMind 每周二、周五更新数据，网站不会自己更新，要点「更新数据库」：它把整个文件重新下一遍，和正在用的一样时什么都不改。
  - 换一种：选另一个数据库，按钮变成「下载数据库」，下好、检查通过以后才替换正在用的，原来那个文件随后删掉。以前记下的归属地不变（比如换成国家数据库以后，旧记录还显示到城市）；要统一的话，勾上「已有归属地的也重新查一遍」再补全。
  - 「查一个 IP」用现在的数据库查任意地址。
  - 补全历史记录：启用之前（或还没有数据库时）记下的 IP 没有归属地，点「补全归属地」用现在的数据库查一遍，写进记录里；勾上「已有归属地的也重新查一遍」时全部重查，更新数据库以后用。只写入归属地，记录的其他内容不变。归属地是记录那一刻查的，IP 段以后换了归属，旧记录不会自己变。
  - 停用后不再查询，也不显示；已经记下的归属地留着，再启用时照常显示。
  - 数据库文件不在数据库备份里：换了服务器、或者恢复备份以后文件不在的话，页面上会提示，重新下载一次就好。
- 错误页：400、401、403、404、413、429、500、502 都是网站自己的 Material Design 3 页面，就在出错的地址上显示（不跳转）；接口回答同样的状态码和 JSON。
- 界面：Material Design 3。配色是 M3 用 #1E6FD9 算出来的一整套颜色，浅色、深色都有，默认跟着系统，也可以在菜单里选。左边是导航栏，管理员放进去的存储源排在下面；手机上导航栏移到屏幕底部（只有一项时不显示），不带存储源；按钮、输入框、菜单、对话框、提示条都是 M3 的样式，按下时有波纹，键盘也能操作。
- 语言：简体中文和英文。页面按浏览器的语言（`Accept-Language`）显示，在顶栏的语言菜单里选过以后按选的（存在 Cookie `hfile_language` 里）；两种都不是时用中文。接口的错误说明也是这个语言。命令行的输出、启动时的错误和新建的 `config.toml` 按系统的语言：`LANGUAGE`、`LC_ALL`、`LC_MESSAGES`、`LANG` 里第一个设了的，`en` 开头的是英文，别的是中文。

## 部署

- 安装向导：第一次启动时（设置文件 `config.toml` 里还没有密钥），整个网站就是一个安装页面。分四步填：安装口令、数据库（SQLite 或 MySQL）、网站、第一个管理员。装好以后程序自己重启成正常的网站，这个页面就打不开了。见[「安装」](install.md)。
- 设置文件 `config.toml`：端口、监听的 IP、数据库、密钥、上传文件和备份放在哪等都写在里面。程序用 `--config` 指定的文件，没指定就用环境变量 `HFILE_CONFIG` 指的，再没有就用程序旁边的，都没有就自动新建一个。写错了启动时一次列出所有问题。见[「设置文件」](configuration.md)。
- 单文件程序：`hfile` 直接运行就是网站，自带 Web 服务器（waitress），静态文件和上传的文件也由它提供。见[「运行」](deploy.md)。
- 升级：换上新版程序再启动，它会自己升级数据库。升级前先备份整个数据库，出错就恢复备份并停下；数据库被新版本升级过以后，旧版本会拒绝启动。随时可以用 `backup` 备份；用 `restore` 恢复要先停掉网站。见[「升级」](upgrade.md)。
